# 0.4.0：真 3D 群系片（列式连通分量）

## 背景

当前片模型是「水平轮廓 + 3D 子状态」：

- 轮廓在固定平面采样（主世界 y=128，无天光维度取维度中部）；
- 位置的实际群系与轮廓群系不同时，key 追加 `|<biome>`。

实测暴露了两个问题：

1. **轮廓平面与玩家高度不一致**时，同一片实际群系会被拆成大量子状态（下界自古如此）。
2. **退化分组的粒度是基础方格**，子状态不参与分组：相邻两个 `g:` 方格若基础群系不同，它们的同一种子状态仍会各自成片（0.3.9 存档里 `g:-1,-1|basalt_deltas`、`g:-1,0|basalt_deltas`、`g:0,-1|basalt_deltas`、`g:0,0|basalt_deltas` 并存即为证据）。

这两点都源于同一个根因：**连通性判定是 2D 的，群系归属是 3D 的**。0.4.0 把两者统一为真正的 3D 连通分量。

## 设计

### 1. 数据模型：列 + 竖直段

- **列**：16×16 方块的竖直柱（与现有粗格一致）。
- **段**：一列内连续同群系的 Y 区间。采样粒度取 **quart（4 方块，群系数据原生分辨率）**，每段记录 `[y0, y1, biomeId]`。
  - 段边界落在 quart 边界上，天气范围与 `level.getBiome(pos)` 的量化完全一致；
  - 已加载区块优先读区块群系调色板（能识别模组改写，如 Meteoros 平流层）；
  - 未加载区块退回噪声采样，不为查天气加载区块。
- **连通定义**：相邻两列的同群系段，只要 **Y 区间相交或接触**，即视为连通（洞穴沿水平延伸、浮岛上下独立、下界立体群系都自然成立）。

### 2. 片 key 与并查集

- 片 = 3D 连通分量，key 形如 `p3:<seedX>,<seedZ>,<seedY>`（seed 为分量内最小的列/段）。
- 分量维护用并查集：
  - 节点是「列段」，键可用 `(columnKey, segmentIndex)` 的 long 编码；
  - 合并只发生在相邻列的段之间；
  - **父指针持久化到 `WeatherData`**（沿用 0.3.9 `fallback_parents` 的做法），保证跨重启 key 稳定。
- 合并时迁移天气状态：保留规范 key（最小 seed）那份，另一份丢弃（结果确定）。

### 3. 查询路径

```
pos → column(x>>4, z>>4) → segment(pos.y) → 分量根 → 规范 key
```

- 沿列做 O(log n) 或线性段查找（段数很少，通常 <10）；
- 每 tick 为玩家所在列建立热缓存；
- `isRainingAt / skyDarkenAt / 刷怪判定` 都走这条路径，不再有「子状态未命中 → 晴天」的伪空档。

### 4. 扫描与预算

新增两级预算（沿用现有每 tick 预算思想）：

| 预算 | 建议值 | 作用 |
|---|---|---|
| `maxColumnScansPerTick` | 4 | 每 tick 最多新增 4 列的竖直采样 |
| `columnScanBudgetNanos` | 2ms | 竖直采样耗时上限 |
| `maxPatchCells` | 保持 16384（粗格） | 单次分量填充上限，超限退化为固定方格 |

- 已加载区块增量扫描，玩家所在列优先；
- 竖直采样次数 = 列数 × section 数（主世界 24、下界 8、末地 16），比 quart 平面填充便宜。

### 5. 退化与超大分量

- 超大分量（海洋、巨型洞穴）仍退化为固定方格，但方格分组以 **列段** 为单位，而不是基础方格；
- 退化方格 key 增加段索引：`g3:<bucketX>,<bucketZ>,<segmentY>`，相邻同群系段一样并查集合并。

### 6. 兼容与迁移

- 新 key 与旧 `p:` / `g:` / `|biome` 不兼容，一次性失效；
- `WeatherData` 版本 8 → 9，加载时丢弃旧 key（保留数采样式清理）；
- 配置新增项给出默认值，旧配置文件自动补全。

## 风险

| 风险 | 应对 |
|---|---|
| 分量合并导致 key 变化 | 规范 key 取最小 seed + 父指针持久化；合并迁移状态 |
| 竖直采样成本 | 段采样取 section 粒度，配预算与增量 |
| 内存（每列段列表） | 按列缓存 + LRU 上限；未加载列的段不常驻 |
| 兼容旧存档 | 一次性失效 + 清理，不做复杂迁移 |

## 测试计划

1. 下界：nether_wastes / basalt_deltas / soul_sand_valley 相邻处，天气按实际群系且同群系连续。
2. 洞穴：lush_caves / dripstone_caves 不再继承地表天气，也不与同层其它洞穴段粘连。
3. 浮岛：上下不相连的同群系各自独立。
4. 主世界：平原/海洋大片连续，河流细长连通，跨 section 不跳变。
5. 强制天气/黑白名单：`b:` 之外的旧配置语义不变。
6. 性能：首次进入新区域、快速飞行、跨维度切换的 MSPT 观测。

## 实施顺序

1. 数据层：`BiomeColumns`（列段采样 + 缓存）
2. 连通层：并查集 + 持久化 + 状态迁移
3. 查询层：替换 `withBiomeSubState` 路径
4. 扫描层：预算接入 `WeatherManager.sweep`
5. 迁移与测试
